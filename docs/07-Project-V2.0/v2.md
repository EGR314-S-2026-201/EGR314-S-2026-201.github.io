## The Duck 2.0
If the team were to create "The Duck 2.0." There would be multiple adjustments to the various sensors and setup we currently have. Due to class constraints, we were required to have one microcontroller per person and to have all systems talk to one another. Now, in version 2.0, the smart thing to do is to make this project have only 2 microcontrollers (One on the controller and one on the boat). This would simplify our setup and allow for a much more established connection throughout the team as we reduce the number of devices in the CAN Bus system (daisy-chaining in class terms). 

Also, by using the wireless system we can have each microcontroller as part of a hub and spoke system with the controller at the center. This would help the efficiency of the subsystems while they communicate with each other. With the number of subsystems, if we were not able to reduce the number of microcontrollers, having two hub and spoke systems that are then centered around the wireless system could improve efficiency by directly wiring it to each subsystem it is communicating with.

Another change that we could make would be the addition of multiple OLED screens for improved readability and a better connecting system to the boat after it docks and needs to transfer images. Furthermore, we would eventually want the boat to be able to send pictures directly to the controller or some other wireless database if possible. This would ensure the SD card on the camera does not run out of storage space and allow real-time decisions on whether to take more pictures or move to a new location. These changes would be far in the future while we work on a floatable outer shell and make the whole system sea-worthy.

## The Duck 2.0
If the team were to create "The Duck 2.0." There would be multiple adjustments to the various sensors and setup we currently have. Due to class constraints, we were required to have one microcontroller per person and to have all systems talk to one another. Now, in version 2.0, the smart thing to do is to make this project have only 2 microcontrollers (One on the controller and one on the boat). This would simplify our setup and allow for a much more established connection throughout the team as we reduce the number of devices in the CAN Bus system (daisy-chaining in class terms). 

Also, by using the wireless system, we can have each microcontroller as part of a hub and spoke system  with the controller at the center. This would help the efficiency of the subsystems while they communicate with each other. With the number of subsystems, if we were not able to reduce the number of microcontrollers, having two hub and spoke systems that are then centered arounf the wireless system could prove to add efficiency because the board would directly wire where each subsystem is communicating to. 

Another change that we could do would be the addition of multiple OLED screens and a better connecting system to the boat after it docks and needs to transfer images. This would be far in the future while we work on a floatable outer shell and make the whole system sea-worthy.

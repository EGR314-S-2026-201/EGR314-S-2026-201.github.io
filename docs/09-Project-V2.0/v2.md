## The Duck 2.0
If the team were to create "The Duck 2.0." There would be multiple adjustments to the various sensors and setup we currently have. Because of class constraints, we were required to have one microcontroller per person and to make all of the systems talk amongst themselves. Now, in version 2.0, the smart thing to do is to make this project have only 2 microcontrollers (One on the controller and one on the boat). This would simplify our setup and allow for a much better-established connection throughout the team as we drop the number of devices in the CAN Bus system (daisy chain in class terms).
